


🌱 Manejo Finca La Carolina
Aplicación web para llevar el control básico de las actividades económicas y productivas de la Finca La Carolina.

La aplicación está pensada para ser sencilla de utilizar desde computador o teléfono y permite registrar, consultar, editar y eliminar información de la finca.

📋 Funciones principales
💰 Ventas y gastos
Permite registrar movimientos económicos de la finca:

Ventas

Gastos

Nómina

Servicios públicos

Insumos

Transporte

Otros movimientos

Cada registro puede incluir:

Fecha

Tipo de movimiento

Categoría

Descripción

Monto

Los movimientos también pueden editarse o eliminarse.

🌱 Producción
Permite registrar la producción de la finca por fecha.

Productos contemplados:

☕ Café

🍌 Plátano

🥚 Huevos

🍋 Limón

🍊 Naranja

📦 Otros productos

Dependiendo del producto se pueden registrar diferentes unidades y características, como calidad, cantidad y detalles.

Los registros de producción pueden editarse o eliminarse.

📦 Inventario
Permite llevar un control de los productos y elementos disponibles en la finca.

Se puede registrar:

Producto o elemento

Cantidad

Unidad

Fecha

Detalle

Los registros de inventario también pueden editarse o eliminarse.

📝 Bitácora
La aplicación cuenta con una bitácora para registrar notas y acontecimientos relacionados con la finca.

🔎 Búsqueda por fecha
Permite consultar los movimientos registrados utilizando la fecha.

💾 Copias de seguridad
La aplicación incluye opciones para realizar copias de seguridad y restaurar la información.

El respaldo completo contempla:

Ventas y gastos

Producción

Inventario

Bitácora

Esto permite conservar una copia de los datos y recuperarlos cuando sea necesario.

🔐 Acceso
La aplicación cuenta con un sistema de usuario y contraseña para acceder al panel principal.

Las credenciales actuales se encuentran configuradas dentro del código JavaScript del proyecto.

Recomendación: si el proyecto se publica públicamente en GitHub, se recomienda cambiar las credenciales y evitar guardar contraseñas reales directamente en el código.

💾 Almacenamiento de datos
La aplicación utiliza el almacenamiento local del navegador mediante localStorage.

Esto significa que los datos se guardan en el navegador y en el dispositivo donde se utiliza la aplicación.

Por esta razón, es importante realizar copias de seguridad periódicamente.

Si se borran los datos del navegador o se cambia de dispositivo, la información almacenada localmente puede dejar de estar disponible. El archivo de respaldo permite recuperar la información cuando corresponda.

🛠️ Tecnologías utilizadas
El proyecto está desarrollado con tecnologías web básicas:

HTML5

CSS3

JavaScript

LocalStorage

CSV para copias de seguridad

No requiere una base de datos externa para funcionar en su configuración actual.

La aplicación está diseñada con una interfaz adaptable para diferentes tamaños de pantalla.

Puede utilizarse desde un navegador en:

Computador

Laptop

Teléfono

Tablet

Si el proyecto se publica mediante GitHub Pages u otro servicio de alojamiento web, puede abrirse desde el navegador del teléfono utilizando el enlace correspondiente.

🚀 Ejecución local
Para ejecutar el proyecto en un computador:

Descargar o clonar el proyecto.

Abrir la carpeta en Visual Studio Code.

Abrir el archivo index.html.

Ejecutarlo utilizando un navegador web.

También puede utilizarse una extensión como Live Server en Visual Studio Code para ejecutar el proyecto durante el desarrollo.

🔄 Recomendaciones de uso
Para evitar perder información:

Registrar los movimientos diariamente.

Revisar periódicamente los datos.

Realizar copias de seguridad.

Guardar los archivos de respaldo en un lugar seguro.

Antes de cambiar de dispositivo, realizar un respaldo.

🎯 Objetivo del proyecto
El objetivo de Manejo Finca La Carolina es facilitar el control de las actividades económicas, productivas y de inventario de la finca mediante una aplicación sencilla y accesible.

El proyecto puede continuar creciendo con nuevas funciones según las necesidades de la finca.
